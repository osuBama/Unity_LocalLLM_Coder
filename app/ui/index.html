    How the model reaches them

    Every tool your client offers the model (OpenClaw's own and each MCP server's) appears here automatically after its first request, grouped by source. The model never sees this page, only the result: Off: removed, and calls to it are blocked. Automatic: full definition on every request. On demand: one line in a catalog; the model loads it when needed, for the rest of that conversation.

    Grouping rules

    Tools are grouped by name prefix (e.g. unity__read_console → unity). Rules override that: the first matching pattern wins (* and ? wildcards).

    Changes are written to config.yaml with a backup; your comments are kept. Settings marked “applies now” take effect immediately; the others after restarting the orchestrator.
